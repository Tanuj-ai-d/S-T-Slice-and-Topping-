# S & T (Slice and Topping) 🍕

**Where Every Slice Belongs** — a responsive pizza shop website for a wood-fired pizzeria in Nagpur, built with only **HTML, CSS and Bootstrap 5.3**.

## Features

- Sticky, mobile-friendly navbar (Bootstrap collapse)
- "Recipe Book" menu with 9 items, tagged Vegetarian / Non-Veg
- CSS-only menu filter (All / Vegetarian / Non-Veg), no JavaScript needed
- Combos & Deals section with promo codes: `WEEKEND25`, `BDAYTREAT`, `LUNCH150`
- Photo gallery section
- Order buttons that open WhatsApp with the item name pre-filled
- Visit Us section with address, phone, opening hours and Google Maps link

## Tech Stack

- HTML5
- CSS3
- [Bootstrap 5.3.3](https://getbootstrap.com/) (via CDN)
- Google Fonts: Fredoka and Nunito (via CDN)

## Getting Started

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   ```
2. Open `index.html` in any browser. No build step or installation required.

An internet connection is needed to load Bootstrap and Google Fonts from the CDN.

## Customizing

- **Menu and combo items:** edit the `.card` blocks in the `#menu` and `#combos` sections of `index.html`.
- **WhatsApp number:** replace `919823045190` in the Order links.
- **Gallery photos:** replace the emoji in the gallery cards with `<img>` tags.
